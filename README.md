# STILLTIME Scripting Language

A text scripting language I created for STILLTIME, my entry into the GMTK Game Jam in 2026.
StillTimeScript, or STS, is a simple and extensible language intended primarily for scripting
games such as text adventures and visual novels.

## Features

- Branching dialogue with configurable speakers, choices, and unlock conditions.
- Graph exploration to find unexplored routes.
- Extensible with custom commands and/or custom UI handling.
- Support for defining macros in script.
- Edit-mode script auto-validator.

## Sample Setup

The following files are found under the 'SampleSetup' directory.

1. Create a new scene and drag in the 'SampleRunner' prefab.
2. Drag 'SampleScript.sts' into your project's 'StreamingAssets' directory, creating the directory if needed.
3. (Optional) Unpack the SampleRunner object in the scene.
4. Run the scene.
